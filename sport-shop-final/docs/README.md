# Sport Shop Online — Proyecto Final JavaScript

Simulador educativo de compra de camisetas de fútbol argentino.

## Funcionalidades

- Catálogo desde `assets/data/productos.json` usando `fetch`, `async/await`, `try/catch/finally`.
- Búsqueda, filtros, orden y control de stock.
- Carrito con altas, modificaciones, eliminación de artículos y vaciado.
- Persistencia en `localStorage` del carrito, cupón e historial.
- Cupón `SPORT10` (10% de descuento).
- Formulario de compra y confirmación con SweetAlert2.
- Historial de compras y restauración del stock simulado al borrarlo.
- Interfaz adaptable a celular y escritorio.

## Tecnologías

HTML5, CSS3, JavaScript ES6+, JSON, Fetch API, LocalStorage y SweetAlert2 desde CDN.
